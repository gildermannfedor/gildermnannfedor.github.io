Вход, скин и RP-Mode

Пароль, собственный скин, подтверждение лицензии и надголовная отметка RP.

Оглавление статьиВход с паролемСвой скинПодтверждение лицензииНадголовная отметка RP-Mode

Вход с паролем#

При первом входе откроется окно регистрации. Придумайте отдельный пароль для ERRATIS, введите его дважды и подтвердите. При следующих входах укажите тот же пароль в окне входа. Не сообщайте пароль другим игрокам.

Если отменить окно или ввести неверный пароль, вход не завершается. При проблемах со своим аккаунтом обратитесь к организатору.

Свой скин#

Введите /skin set <ник>, например /skin set Steve, чтобы выбрать для себя скин по имени. Выбранный скин сохраняется для следующих входов. Команда меняет внешность, а не владельца аккаунта или его игровой прогресс.

Подтверждение лицензии#

Владелец лицензионной копии Minecraft может после входа с паролем включить /premium. Затем нужно переподключиться с лицензионного аккаунта. Вход без пароля возможен после успешного подтверждения лицензии. Сохраняйте свой пароль: само включение команды не означает, что подтверждение уже состоялось.

Надголовная отметка RP-Mode#

КомандаДействие
/rpmode onВключить отметку над головой
/rpmode offВыключить отметку
/rpmode statusПосмотреть состояние

Это косметическая отметка готовности к ролевому взаимодействию. Она не меняет урон, скорость, защиту территории или ограничения PvP. Включение отметки само по себе не означает согласия на нападение, пленение или окончательную RP-смерть. Правила официальной войны действуют независимо от метки.

В TAB отдельно показывается выбранный народ. Для правильного отображения плашек подключите ресурспак сервера. Плашки шести народов.
